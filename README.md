# Conozcamos nuestra memoria y cuidemos nuestra salud mental

> **Una guía sencilla para entender tu evaluación, conocer tus capacidades y cuidarte cada día.**

Cartilla psicoeducativa digital e interactiva diseñada para pacientes y familiares. Permite comprender el proceso de una evaluación neuropsicológica, las pruebas utilizadas, el significado de los resultados en la vida cotidiana, cómo funciona la memoria y pautas prácticas de cuidado y acompañamiento familiar.

## 🌟 Características

- **11 Capítulos ordenados:** Desde la bienvenida y el motivo de evaluación hasta las recomendaciones y el plan de compromisos.
- **7 Pruebas explicadas didácticamente:**
  1. Índice de Barthel (actividades básicas)
  2. Escala de Lawton y Brody (actividades instrumentales)
  3. Escala de Yesavage (GDS-15, estado de ánimo)
  4. DASS-21 (depresión, ansiedad y estrés)
  5. NEUROPSI Breve (tamizaje cognitivo global)
  6. BANFE-3 (funciones ejecutivas y lóbulos frontales)
  7. WAIS-IV (capacidad intelectual general y reserva cognitiva)
- **Actividades didácticas interactivas:**
  - *Actividad A:* El recorrido de un recuerdo (atención, almacenamiento y evocación).
  - *Actividad B:* Una estrategia para cada situación cotidiana.
  - *Actividad C:* Mitos y realidades sobre la memoria y el envejecimiento.
  - *Actividad D:* Mi pequeño plan de cuidado (con resumen imprimible).
- **Accesibilidad y diseño adaptable (WCAG 2.2 AA):**
  - Controles para aumentar y reducir tamaño de texto (A+ / A-).
  - Control para reducir animaciones (`prefers-reduced-motion`).
  - Navegación completa por teclado con foco visible.
  - Modo dual: *Explicación breve* y *Quiero saber un poco más* (con tablas clínicas).
  - Formato listo para impresión optimizado (`@media print`).
  - 100% responsivo para móviles, tablets y computadores.

## 🚀 Cómo ejecutar localmente

No requiere instalación de librerías ni dependencias pesadas.

1. Clona el repositorio o descarga los archivos.
2. Abre `index.html` en cualquier navegador web moderno (Chrome, Edge, Firefox, Safari).

## 🛠️ Tecnologías

- **HTML5 semántico**
- **CSS3 Vanilla** (variables de diseño, flexbox, grid, animaciones accesibles)
- **JavaScript Moderno** (ES6+)
- **SVG Vectorial Inline** (ilustraciones y escenas interactivas ligeras)
